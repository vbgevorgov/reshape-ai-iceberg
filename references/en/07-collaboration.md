# Real subagents and purposeful diagrams — optional

When actual subagent tools are available, parallelize independent domain, data, architecture, assurance and cost investigations. Each real worker must receive a specific question, sources, evidence standard, action constraints and output. The lead reconciles contradictions before recommendations.

Without actual subagent tools, use sequential analytical perspectives and never simulate tool execution or worker progress.

Create visuals only when they convey workflow ownership, contract dependencies, trust boundaries, decision flow or scenario economics. Prefer concise diagrams over decorative pictures or fabricated UI.
